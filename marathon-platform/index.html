    关于这个版本
    · 当前为本地版:档案与关注清单保存在你自己的浏览器里,换设备不会自动同步。
    · 收录马拉松 / 路跑与越野赛两类赛事,全程分类展示:赛事库按类型分区、我的关注可按类型筛选、看板顶部给出两类各自的进行中数量。两类在赛制、资格门槛与材料要求上完全不同 —— 越野赛普遍需要 ITRA 表现分、UTMB 指数或跑石,且赛前强制装备逐项检查。
    · 日期均标注了可信度:官方公告 / 媒体多源 / 按往年推算 / 待公布 —— 最终以组委会官方公告为准。越野赛的报名窗口公布得普遍比路跑晚,「待公布」占比较高属正常。
    · 状态判断由 assets/engine.js 统一提供,页面、每日巡检脚本与后续小程序共用同一份逻辑,不会出现"网页说待缴费、提醒说已截止"。
    · 界面动效纯 CSS 实现,系统开启「减少动态效果」后自动全部静止。
